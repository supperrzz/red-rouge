# Red Rouge Day Spa Homepage Plan

## 1. Hero Section (Slider)
**Content**: Full-screen slider with spa atmosphere visuals
**Components**: 
- React Slick Slider (from index3.js)
- Theme buttons (style-six/style-five)
**Visuals**: Unsplash images for:
- Relaxing massage room
- Facial treatment
- Spa relaxation area
**Intent**: Establish premium brand identity and key services

## 2. Featured Services Grid
**Content**: 6 core services with images/descriptions
**Components**: 
- ServiceItem component (from services.js)
- Wow.js fadeIn animations
**Services**:
1. Therapeutic Massages
2. Advanced HydraFacials
3. Body Contouring
4. Aromatherapy
5. Couples Packages
6. Wellness Consultations
**Intent**: Showcase key services with clear CTAs

## 3. Wellness Counter Section
**Content**: Achievements/stats visualization
**Components**: 
- CounterSection component
- Counter component with animations
**Metrics**:
- Satisfied Clients
- Expert Therapists
- Years Experience
- Treatment Options
**Intent**: Build credibility through social proof

## 4. Signature Experience
**Content**: Curated treatment packages
**Components**:
- BSAccordion for package details
- ImageView component for galleries
**Packages**:
- Ultimate Relaxation Journey
- Bridal Wellness Prep
- Corporate De-stress Program
**Intent**: Highlight premium offerings

## 5. Testimonials Carousel
**Content**: Client success stories
**Components**:
- FeedBackSliderWithLogo
- Testimonial cards with client photos
**Intent**: Build trust through social validation

## 6. Booking CTA Section
**Content**: Interactive booking widget
**Components**:
- Booking hours component (from index3)
- react-nice-select for time slots
**Features**:
- Online availability check
- Package selector
- Gift certificates
**Intent**: Drive conversions

## 7. Wellness Blog Preview
**Content**: Latest articles carousel
**Components**:
- PortfolioMasonryIsotop layout
- Blog grid items with hover effects
**Topics**:
- Self-care techniques
- Treatment deep dives
- Seasonal specials
**Intent**: Establish thought leadership

---

**Design System**:
- Font: Oswald/Mulish from existing CSS
- Colors: Serene palette (sage greens, muted golds)
- Animations: Wow.js scroll triggers
- Layout: Bootstrap grid system
- Images: Unsplash curation with consistent filters

**Dependencies**:
- react-slick for sliders
- isotope-layout for masonry
- wowjs for animations
